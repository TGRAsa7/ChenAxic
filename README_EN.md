# ChenAxic — OTG Flashing Tool


An Android flashing tool based on **OTG connection**. Flash other devices directly from your phone — no PC required.

## ✨ Highlights
- Supports **Xiaomi / OPPO / Realme / OnePlus** firmware flashing
- Supports **Fastboot / FastbootD / 9008 (EDL)** three modes
- Flash target devices directly via **OTG cable** from your phone

---

## 📱 Flashing (Home)

- **Qualcomm QDL**: Qualcomm 9008 deep flash — VIP authorization, OFP/OPS extraction, QFIL flashing, flash/extract/erase images, Oplus deep flash, full package flashing, partition table detection, A/B slot switching
- **Oplus flashing**: OPPO / Realme / OnePlus flashing (including preloader)
- **Mi Flash**: scan directory for *.sh scripts and execute
- **Flash partition**: fastboot flash boot / dtbo / init_boot / recovery etc.
- **Flash KernelSU**: one-click patch init_boot / boot and flash
- **ADB Sideload**: supports OTA package or AnyKernel3
- **Reboot**: reboot device via ADB / Fastboot
- **Detect device**: detect ADB / Fastboot / Recovery / 9008 device

## 🧰 Tools

- **ADB**: view device info, install APK
- **Fastboot**: fastboot operations
- **7z extract**: extract archives
- **payload.bin extract**: extract OTA payload.bin
- **Quick links**: common links
- **Developer mode**: debug options (including file debug)

## ⚙️ System (Settings)

- **Theme**: light / dark / follow system + Monet dynamic color
- **Terminal**: built-in shell terminal
- **About**: app info, credits, sponsor

---

## ⚙️ Requirements
- Device requires **root / su** permission
- Connect target device via **OTG cable**
- Android 11+
